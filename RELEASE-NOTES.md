## Türkçe

**Arayüz**
- Windows 11 tarzı Fluent görünüm eklendi. Launcher Ayarları’nda kare ve yuvarlak düğmeler arasında anında geçiş yapılabiliyor. Açılır listeler, giriş alanları ve kurulum sihirbazı seçilen biçime uyuyor.
- Material You kendi renkli yüzeylerini koruyor. Diğer temalarda koyu arka planlar nötr kalıyor ve tema rengi düğmeler ile etkileşim vurgularında kullanılıyor. Hakkında sayfasındaki Hata Bildir ve Öneri düğmelerinin dolgusu artık görünür.
- Simge seçicide Tilki ve Oyun kumandası seçenekleri var. Simge rengi açıldığında tema izleniyor, kapatıldığında klasik beyaz kullanılıyor. Windows başlangıç bildirimi kaldırıldı.

**Minecraft, modlar ve Discord**
- Minecraft’ta algılanan Final ve Önizleme kurulumları arasında ana ekrandan geçiş yapılabiliyor. Denenen Sürümler ve Mod Yöneticisi kaldırıldı. Modlar sayfası tekrar yerel dosya seçimi ve sürükle bırak akışını kullanıyor.
- Ana ekrandaki Modloader’ı kur düğmesi kaynak ile Content hedefini gösteriyor. Var olan bir dosyanın üzerine yazmadan önce ayrı bir onay istiyor.
- Discord RPC, Minecraft sürümü ve oturum süresini paylaşabiliyor. İsteğe bağlı, tek dosyalık Windows x64 etkinlik DLL’i açık yerel dünyayı algılıyor. Dünya adı paylaşımı varsayılan olarak kapalı. Desteklenen veri yoksa launcher temel oyun durumunu gösteriyor.

**Diğer düzeltmeler**
- Skin editörüne damlalık eklendi. Steve/Alex, Vazgeç ve Kaydet kontrolleri ad alanının sağına taşındı. Sunucu çöp kutusu simgesi, anahtar imleçleri ve Dünyalar’daki CurseForge bağlantısı düzeltildi.
- Güncellemeden sonra Ayarlar, eski kurulum dosyalarını silmek için onay istiyor. Temizlik gelişmiş ayarlardan elle de başlatılabiliyor.
- Launcher ve Windows x64 kurulum paketi .NET 10’a taşındı.

## English

**Interface**
- Added a Windows 11-inspired Fluent appearance. Switch between square and rounded buttons in Launcher Settings and preview the change immediately. Menus, fields, and the setup wizard follow the selected shape.
- Material You retains its tinted surfaces. Other themes keep neutral dark backgrounds and use theme colors for buttons and interaction highlights. Report a Bug and Suggest an Idea now have visible button fills on the About page.
- Choose a Fox or Controller icon. The icon color follows the theme when enabled and uses classic white when disabled. Removed the Windows startup notification.

**Minecraft, mods, and Discord**
- Switch between detected Minecraft Release and Preview installations on Home. The experimental Versions and Mod Manager pages were removed. The Mods page again supports local file selection and drag-and-drop.
- Install Modloader on Home shows the download source and Content destination. Replacing an existing file requires separate confirmation.
- Discord RPC can share the Minecraft version and playtime. The optional single-file Windows x64 activity DLL detects an open local world. World name sharing is off by default. The launcher shows basic game activity when detailed data is unavailable.

**Other fixes**
- Added an eyedropper to the skin editor and moved the Steve/Alex, Cancel, and Save controls next to the name field. Fixed the server trash icon, toggle cursors, and the CurseForge link in Worlds.
- Settings offers to remove old installer files after an upgrade. Cleanup is also available manually in advanced settings.
- The launcher and Windows x64 installer now use .NET 10.
