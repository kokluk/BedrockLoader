## Türkçe

**Minecraft kaynak kullanımı**
- Özelleştirme’den açıldığında Minecraft modunda sol menüye Kaynak kullanımı ekleniyor. Canlı CPU ve RAM ölçümleri yeşil kartlarda gösteriliyor.
- Bildirim eşikleri temalı giriş alanlarından kaydediliyor. Eşiği 0 olan kaynak için bildirim gönderilmiyor. Pozitif eşik aşılırsa Yüksek kaynak kullanımı uyarısı geliyor.

**Dünyalar ve görünüm**
- Dünyalar → CurseForge akışı ve Bedrock harita kategorisi düzeltildi. API Key düğmesi kişisel anahtarı Windows hesabına bağlı olarak şifreli saklıyor. Web sitesini aç düğmesiyle haritalar tarayıcıda gezilebiliyor.
- Kare düğmeler, biçim tercihi kaydedilmemiş kurulumlarda varsayılan. Mevcut tercihler korunuyor.
- Skin editöründe ad kutusu kısaltıldı. Steve/Alex, Vazgeç ve Kaydet eşit genişliğe sahip. Kaydet etiketi tam görünüyor ve tuvalin köşeleri yuvarlatıldı.

**Discord Rich Presence**
- Sunucu adresi, Realm adı ve yerel dünya adı paylaşımı hem RPC ayarlarından hem kurulum sihirbazından kaldırıldı. Önceki tercihler bu bilgileri paylaşmıyor.

## English

**Minecraft resource usage**
- Enable tracking in Customization to add Resource Usage to the Minecraft sidebar. Live CPU and RAM readings appear on green cards.
- Set notification thresholds using the themed fields. A threshold of 0 disables notifications for that metric. Exceeding a positive threshold triggers a High Resource Usage alert.

**Worlds and appearance**
- Fixed Worlds → CurseForge navigation and Bedrock map category lookup. API Key stores your personal key encrypted for your Windows account. Open Website lets you browse maps in your browser.
- Square buttons are the default when no shape preference is saved. Existing preferences are preserved.
- Shortened the skin name field. Steve/Alex, Cancel and Save have equal widths, the full Save label is visible, and the canvas has rounded corners.

**Discord Rich Presence**
- Removed server address, Realm name and local world name sharing from RPC settings and the setup wizard. Previous preferences no longer share these details.
